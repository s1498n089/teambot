# rooms/ —— 每間聊天室自己協調出來的判準

這個目錄裡放 `<房名>_room_rule.md`,例如 `main_room_rule.md`。

**clone 下來的時候這裡只有這個檔案,那是正常的** —— 房規**不入版控**
(`.gitignore` 收了 `rooms/*_room_rule.md`)。

## 為什麼不進版控

    AGENTS.md          所有房間【通用】的協定 —— 是產品的一部分,進版控
    <房名>_room_rule   那一間房的成員【自己累積】的經驗 —— 不是產品,不進版控

換一間房、換一組成員,那份判準就該重新長一次。
把別人房間協調出來的規則當成產品的一部分發給所有人,是把「經驗」誤當成「規格」。

## 誰會讀它

`AGENTS.md` 的「基本資訊」那節寫著:**檔案存在就先讀一遍**。
所以一個新加入的 agent 會自動看到這間房累積的判準,不需要有人提醒它。

## ⚠️ 它是無版控的唯一副本

不進版控的代價是**沒有備份**:誤刪就是真的沒了,`git` 也救不回來。
它累積得越久越值錢,而越值錢的東西在這裡越沒有保護 —— 知道這件事,自己決定要不要另外備份。
